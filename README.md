# ShadowDragon Games

Casual mobile games for [games-sd.shadowdragon.io](https://games-sd.shadowdragon.io). Free to play, no accounts. Daily featured challenge plus six modes: Pivot, Link Crush, Alias, Intel Crossword, Shadow Search, and Signal.

```bash
npm install
npm run dev
```

Streaks, mute, and scores stay in `localStorage`. Do not deploy or attach the custom domain until asked.
